# 말씀알림 프로젝트 인수인계 (Claude 세션 요약)

> 이 문서는 Claude와 나눈 기획 세션을 다른 AI(GPT 등)가 이어받을 수 있도록 정리한 것입니다.

## 1. 한 줄 요약

**말씀알림(가칭)**: 어르신이 혼자서도 쓸 수 있는 가장 쉬운 성경 **앱**(앱스토어·구글 플레이 배포).
우리 교회 목사님의 매일 묵상을 큰 글씨 **글자**로 받아 읽고 듣고, 주일에는 목사님이 지정한 설교 본문이 첫 화면에 바로 뜬다.

## 2. 세션에서 한 일 (시간순)

1. **예시 웹페이지 제작**: 가상의 빵집 "새벽반죽 베이커리" 소개 페이지(HTML 한 장).
2. **GitHub Pages 배포**: 저장소 `JordonPark/saebyeok-bakery`에 올리고, GitHub Actions(`.github/workflows/deploy.yml`)로 main 푸시 시 자동 배포.
   - 주소: https://jordonpark.github.io/saebyeok-bakery/
   - Pages 설정(Source: GitHub Actions)은 사용자가 직접 켬. 이 패턴을 말씀알림의 묵상 파일 배포에도 재사용할 계획.
3. **성경 데이터 확보**: 공개 저장소 [thiagobodruk/bible](https://github.com/thiagobodruk/bible)의 JSON으로 **개역한글(ko_krv, 66권·31,103절) + KJV(66권·31,102절)** SQLite DB를 만듦(약 29MB, FTS5 trigram 전문 검색 색인 포함).
   - 테이블: `translations`, `books(translation, book, abbrev, name, testament)`, `verses(translation, book, chapter, verse, text)`, `verses_fts`
   - 개역한글 JSON 크기: 원본 약 4.4MB, gzip 약 1.2MB (직접 측정)
   - **이 데이터는 개발용 임시 데이터**다. 출시는 개역개정(허가 필요).
4. **기획서 작성 및 수차례 수정**: Claude Docs 문서 "말씀알림 서비스 기획서"(아래 5장에 전문 요약).

## 5. 현재 기획서 내용 (요약 전문)

### 5-1. 개요
- 어르신 중심(핵심): 큰 글씨, 버튼 세 개, 소리로 듣기, 가족이 대신 해 주는 설정
- 목사님 묵상을 글자로: 매일 묵상(제목·성경·묵상·적용·기도)을 이미지가 아닌 큰 글씨 글자로. 묵상 속 성경 구절을 누르면 그 장이 열림
- 데이터 걱정 없음: 앱은 성경 없이 가볍게 설치(1차), 성경 전체는 와이파이에서 한 번만(2차). 매일 묵상은 수 KB
- 성경책: 목차에서 책·장 골라 넘겨 읽기, 이어 읽기
- 주일 말씀: 지정된 설교 본문이 주일 첫 화면에
- 기억나는 대로 검색: "하나님이 세상을 사랑해서" → "이처럼 사랑하사"

### 5-2. 지금 방식과 바꿀 점 (시범 교회 현황)
시범 교회는 목사님 매일 묵상을 **배경 사진이 들어간 이미지**로 만들어 카톡으로 돌림. 교회 공지가 속회·선교회를 거쳐 전달되는데 "알림을 받지 못해 소외되는 교우가 없도록" 따로 부탁할 만큼 누락이 생김.

| | 지금(묵상 이미지를 카톡으로) | 말씀알림 |
| --- | --- | --- |
| 글씨 | 확대하면 줄이 화면 밖으로 밀림 | 글씨 크기에 맞춰 줄 자동 바뀜 |
| 듣기 | 불가 | 묵상·기도 읽어 줌 |
| 성경 구절 | 앞뒤 본문을 따로 찾아야 함 | 누르면 그 장이 열림 |
| 데이터 | 이미지 한 장 약 0.8MB(받은 5장 기준) | 묵상 한 편 약 3KB |
| 지난 묵상 | 대화방을 거슬러 올라가야 함 | 날짜별 목록·검색 |
| 받는 사람 | 단톡방·속회 연락에 의존 | 앱 설치하면 매일 알림 |

### 5-3. 목표와 대상
| 대상 | 불편 | 필요 |
| --- | --- | --- |
| 어르신 성도(60대 이상, 주 사용자) | 작은 글씨·복잡한 메뉴, 돋보기·종이 성경, 예배 중 본문 찾기 어려움, 데이터 요금 걱정 | 큰 글씨, 적은 버튼, 듣기, 데이터 거의 안 쓰는 앱 |
| 자녀·가족 | 부모님 휴대폰 설정을 대신 해야 함 | 부모님 폰에 설치하고 한 번에 설정하는 쉬운 첫 화면 |
| 교회 담당자(목사, 구역장) | 설교 본문을 알려도 어르신이 예배 중 못 찾음 | 주일 본문을 한 번 입력하면 성도 화면에 바로 표시 |

성공 지표(제안): 알림→구절 화면까지 탭 1번 / 시범 교회 어르신 4주 뒤 알림 유지 비율 / 처음 쓰는 어르신이 도움 없이 검색 성공 비율

### 5-4. 핵심 기능 (MVP = 최소 출시 버전)

**어르신 중심**
- 큰 글씨 화면: 본문 기본 24pt, 3단계, 휴대폰 "글자 크기" 설정 따름. 첫 화면 버튼 3개("오늘의 말씀", "성경 찾기", "듣기")
- 소리로 듣기: 휴대폰 내장 음성, 속도 느리게/보통
- 매일 알림: 매일 오전 8시 1회(시간 선택은 다음 단계), 앱 푸시로 묵상 제목+구절. 누르면 큰 글씨 묵상 화면
- 가족이 대신 설정: 자녀가 설치 → 첫 화면 한 장에서 글씨 크기·교회·알림 허용. 교회는 주보 QR로 자동 선택
- 로그인 없음: 회원가입·비밀번호·전화번호 없음
- 2단계 다운로드: 1차 = 성경을 뺀 가벼운 앱. 2차 = 와이파이 연결 시 성경 전체(압축 약 1.2MB)를 한 번만 받아 저장. 모바일 데이터면 대기. 받기 전에도 오늘 묵상은 볼 수 있음. 완료 후 "성경 저장 완료 · 데이터 없이 읽기 가능"

**성경책**: 목차(구약/신약→책→장, 전체 이름) / 장 넘기기(밀기·"다음 장" 버튼) / 이어 읽기 / 장 듣기(읽는 절 표시) / 책갈피(다음 단계)

**목사님 말씀(매일 묵상 + 주일 본문)**
- 매일 묵상 화면: 제목·성경·묵상·적용·기도로 나눠 표시, 구절 위치(습 1:14-15) 탭 → 그 장
- 묵상 듣기(전체 또는 기도만), 지난 묵상(날짜별)
- 묵상 입력: 목사님이 이미지 만들기 전 글자를 운영자에게 카톡으로 보냄 → "성경:", "묵상:", "적용", "기도" 표시로 자동 분리 → 운영자 확인 후 저장. 전날 밤까지 보내면 다음 날 아침 발송
- 교회 참여(주보 QR/교회 코드), 교회 이름 지정(담당자)
- 주일 본문 지정(운영자에게 카톡으로 → 운영자 저장), 주일 첫 화면(큰 글씨 + 듣기)
- 단톡방 공유(기본 공유 창 → 카카오톡, 무료)
- 교회 소식(다음 단계)

**기억나는 대로 검색**: 요즘 말→성경 말투 변환 사전("사랑해서"→"사랑하사", "말씀하셨다"→"이르시되") + 오타 허용 / 구절 주소 인식("요 3:16", "요한복음 3장 16절", "시편 23편") / 말로 검색(키보드 마이크) / 뜻으로 검색(AI, 다음 단계)

**날마다 보여 주는 말씀**: 평일 = 목사님 그날 묵상, 주일 = 설교 본문. 묵상이 없거나 교회 미참여자 = 365구절 목록에서 하나.

### 5-5. 사용자 흐름
- **가족이 대신 설정**: 앱 설치(1차) → 글씨 크기, 주보 QR로 교회 선택 → "알림 받기"·허용 → 집 와이파이에서 성경 자동 저장(2차) → 테스트 알림
- **어르신의 하루**: 8시 알림 "오늘의 ○○ 묵상 · (제목) (습 1:14-15)" → 탭 → 큰 글씨 묵상 → "듣기" / 구절 탭으로 장 열기
- **성경 찾기**: 기억나는 말 입력 또는 마이크 → 한 화면 3개씩 큰 글씨 결과 → 탭하면 절 강조된 장
- **성경책처럼 읽기**: "이어 읽기" / 목차 / "다음 장"
- **주일**: 아침 알림 "오늘 설교 본문 · 요 3:16-21" → 예배 중 앱 열면 본문이 첫 화면에
- **목사님과 담당자**: 묵상 글자를 운영자에게 카톡 → 운영자 확인·저장 → 다음 날 8시 발송 / 주일 본문도 같은 방식 / 공유로 단톡방에도

### 5-6. 데이터와 저작권
| 판본 | 규모 | 상태 | 사용 |
| --- | --- | --- | --- |
| 개역한글(1961) | 66권·31,103절 | 보호기간 만료로 널리 여겨짐 | 개발용 임시 데이터(출시 제외) |
| KJV | 66권·31,102절 | 퍼블릭 도메인 | 다음 단계(기본 화면 제외) |
| 개역개정 | — | 대한성서공회 저작권. 사용 허가 필요 | **출시 기본 판본(확정)** |
| 새번역·공동번역 | — | 저작권 보호 | 미포함 |
| 목사님 묵상 글 | 매일 1편, 약 3KB | 목사님 저작물, 동의 필요 | MVP 핵심 콘텐츠 |

개역개정 vs 개역한글 예: 창 35:2 "의복을 바꾸어 입으라"(개정) vs "의복을 바꾸라"(한글), 수 24:15 "너희 조상들이 강 저쪽" vs "너희 열조가 강 저편".
개발 시작과 함께 대한성서공회에 허가·데이터 요청, 그동안 개역한글로 개발 후 출시 전 판본 파일만 교체. 묵상 화면의 성경 인용은 목사님 글을 그대로 보여 주므로 판본 무관.

### 5-7. 기술 구성
앱은 Expo(React Native + TypeScript)로 iOS·Android 동시 개발, 서버 없이 GitHub만.

| 용도 | 기술 | 설명 |
| --- | --- | --- |
| 앱 | Expo (React Native + TypeScript) | EAS Build로 맥 없이 빌드·스토어 제출 |
| 2차 다운로드 | expo-network, expo-file-system | 와이파이 확인 후 성경 전체를 책 단위로 받아 이어 받기 |
| 성경 저장·검색 | expo-sqlite | 구절 주소 인식·변환 사전·전문 검색 직접 구현 |
| 듣기 | expo-speech | 휴대폰 내장 한국어 음성 |
| 매일 알림 | Firebase Cloud Messaging **주제(topic) 구독** | 교회마다 주제 하나. GitHub Actions 예약 실행이 매일 아침 그 주제로 발송. 신청자 목록·전화번호 저장 없음. Firebase 키는 GitHub Secrets |
| 묵상·주일 본문 | GitHub Pages의 날짜별 글자 파일 | 운영자가 목사님 글을 붙여 넣으면 Actions가 항목 분리·구절 링크화. 1편 약 3KB |
| 단톡방 공유 | 휴대폰 기본 공유 창 | 카카오 SDK 불필요 |
| 테스트 배포 | TestFlight, 구글 플레이 내부 테스트 | 시범 교회 어르신에게 먼저 |

참고: FCM 주제 구독은 Expo Go가 아니라 개발 빌드(@react-native-firebase/messaging + config plugin)가 필요.

구조도(텍스트): 목사님 → (카톡) → 운영자 → 묵상·주일 본문 파일(GitHub) → GitHub Actions(배포 + 매일 아침 알림 예약) → GitHub Pages(날마다 묵상 약 3KB / 한 번 성경 전체 약 1.2MB) → 말씀알림 앱. Actions → Firebase 푸시(교회별 주제) → 어르신 휴대폰 알림 → 누르면 앱 열림. 앱스토어·구글 플레이 → 앱 설치(성경 없이 가볍게).

### 5-8. 일정과 단계 (날짜 미정)
개발 시작과 함께 개역개정 허가 문의 + 애플·구글 개발자 계정 생성.

| 단계 | 범위 | 완료 기준(제안) |
| --- | --- | --- |
| 1. 어르신 화면(테스트 배포) | 큰 글씨 화면, 목사님 묵상 화면(지난 묵상), 2차 다운로드, 성경책, 듣기, 구절 주소 인식, 기억나는 대로 검색. TestFlight·내부 테스트 | 시범 교회 어르신 5명이 도움 없이 묵상 읽고 듣고 구절 찾기 |
| 2. 알림과 교회, 출시 | 매일 앱 푸시, 가족이 대신 설정, 교회 참여·이름·주일 본문·주일 첫 화면, 단톡방 공유. 개역개정 교체 후 스토어 출시 | 4주 연속 매일 알림, 주일 예배 중 어르신이 지정 본문을 바로 엶 |
| 3. 확장 | 담당자 직접 입력 화면, 받을 시간 선택, 토요일 미리 알림, 교회 소식, 책갈피, 뜻으로 검색(AI, 서버 필요 여부 재검토) | 2단계 반응 보고 결정 |

### 5-9. 리스크
| 리스크 | 영향 | 대응 |
| --- | --- | --- |
| 어르신 혼자 앱 설치·알림 허용 어려움 | 설치 이탈 | 가족·봉사자 설치, 주보 설치 QR, "설치 도움의 날" |
| 개역개정 사용료·허가 조건 | 무료 운영 어려울 수 있음, 허가 늦으면 출시 지연 | 개발 시작과 함께 문의 |
| 스토어 심사(개인정보 처리방침, 최소 기능 기준) | 출시 지연 | 처리방침 페이지 준비(수집 개인정보 없음 명시) |
| 개발자 계정 비용·명의 | 애플 연 99달러, 구글 1회 25달러. 단체 명의는 애플에 D-U-N-S 번호 필요 | 운영 주체(개인/교회) 먼저 결정 |
| 2차 다운로드 전엔 성경책·검색 불가 | 밖에서 설치하면 집에 갈 때까지 성경 못 봄 | 묵상은 바로 사용, 와이파이 안내, "지금 받기(약 1.2MB)" 버튼 |
| 알림 끄기·앱 삭제 | 묵상 못 받음 | 하루 1번, 묵상 제목과 구절만, 홍보 알림 없음 |
| GitHub Actions 예약 실행 지연·건너뜀, 공개 저장소 60일 비활동 시 예약 자동 비활성 | 아침 알림 늦거나 안 감 | 8시보다 일찍 예약, 실패 시 운영자 알림, 매일 묵상 저장으로 활동 유지 |
| 운영자가 묵상·본문 입력을 손으로 함 | 바쁘면 밀림 | 시범은 교회 1곳, 담당자 직접 입력은 3단계 |
| 목사님이 이미지로만 보내심 | 재타이핑·오타 | 이미지 만들기 전 글자 그대로 보내 주시도록 부탁 |
| 주일 본문 입력 누락·직전 변경 | 첫 화면 본문 없음/틀림 | 토요일까지 없으면 담당자 연락, 당일 수정은 앱 열 때 반영 |
| 음성 품질 기기별 차이 | 어색한 목소리 | 시범 기기로 미리 확인 |

## 6. 다른 성경 앱과의 차별점 (세션 결론)

| | 일반 성경 앱 | 말씀알림 |
| --- | --- | --- |
| 매일 말씀 | 앱 회사가 고른 구절 | **우리 목사님 매일 묵상** |
| 주일 | 본문 직접 찾기 | **지정 설교 본문이 첫 화면** |
| 교회 연결 | 없거나 대형 교회 위주 | 주보 QR로 우리 교회, 교회 이름 표시 |
| 대상 | 전 연령, 기능 많음 | **어르신 전용**(큰 글씨, 버튼 3개, 가족 설정) |
| 데이터 | 계속 내려받음, 이미지·광고 | 성경은 와이파이에서 한 번, 이후 하루 몇 KB |
| 검색 | 정확한 단어 필요 | 요즘 말로도 찾음 |
| 가입 | 계정 요구 많음 | 없음 |

솔직한 평가: 개별 기능(큰 글씨, 읽어 주기, 오늘의 말씀)은 흔함. 진짜 차별점은 ① **콘텐츠가 우리 교회 것**(큰 앱이 따라 하기 어려움) ② **어르신에 맞춘 단순함**. 약점: 교회가 묵상을 꾸준히 보내지 않으면 차별점 소멸 → **목사님 묵상 입력을 얼마나 쉽게 만드느냐가 성패**.

## 8. 다음 단계 (바로 할 일)

1. 사용자가 **개발용 GitHub 저장소**를 만든다(예: `malsseum-alim`). Claude 세션 환경은 새 저장소 생성 권한이 없었음.
2. Expo 프로젝트 초기화(TypeScript, expo-router 등), 개발 빌드 설정.
3. 1단계 구현: 큰 글씨 화면 → 묵상 화면(목사님 글 파서 포함) → 2차 다운로드 + SQLite → 성경책 → 구절 주소 인식 → 검색(변환 사전) → 듣기.
4. 묵상 글 파서 테스트 데이터: 목사님 묵상 형식 예시
   ```
   오늘의 ○○ 묵상: (제목)
   성경: "(본문 인용, 개역개정)" (습 1:14-15)
   묵상: (본문)
   적용: (본문)
   기도: (본문) … 아멘.
   ```
   ("성경 :", "적용 :"처럼 콜론 앞 공백, "적용"/"기도" 뒤 줄바꿈만 있는 변형도 있음 → 파서가 둘 다 처리해야 함)
5. 대한성서공회 개역개정 허가 문의, 개발자 계정 준비.
