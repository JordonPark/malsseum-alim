# 교회 코드 발급

교회 등록 시 Supabase의 `register_church` 함수가 코드 하나를 발급한다. 먼저 숫자 6자리를 무작위로 고르고, 모든 숫자 조합이 사용 중이면 알파벳 한 글자와 숫자 다섯 자리로 발급한다. 숫자 코드의 앞자리 0도 유지한다. 개발용 성도·관리자 입장 코드와 폐기한 예시 코드는 발급 대상에서 제외한다. 발급은 한 트랜잭션에서 처리하고 DB의 고유 제약이 코드 중복을 차단한다.

[Supabase 마이그레이션](../supabase/migrations/20261119000100_church_codes.sql)을 적용하면 서버에서 교회 ID(UUID)와 이름을 넘겨 `register_church`를 호출할 수 있다. 같은 교회 ID로 재시도하면 처음 발급한 코드를 반환한다. 발급 함수는 `service_role`만 실행할 수 있다. 공개 조회는 `lookup_church_by_code`에 코드를 전달하며, 일치하는 교회의 이름과 코드만 반환한다. GitHub Pages 웹앱의 교회 등록과 공개 조회 연결은 Supabase 프로젝트 설정이 필요하다.
