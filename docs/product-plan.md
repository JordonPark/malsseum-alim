# 오늘의 교회 기획서

**서비스명**　오늘의 교회

**소개 문구**　우리 교회 말씀·주보·온라인 예배

작은 교회를 위해 주보와 예배 정보를 정리하고 말씀을 전달하는 운영 도구다. 교회 관리자는 교회 기본 정보, 예배 일정과 온라인 예배 링크, 말씀과 주보, 담당자 권한을 한곳에서 관리한다. 필요한 내용을 게시하면 성도는 교회 코드, QR 또는 카카오톡 링크로 접속해 공개된 정보를 로그인 없이 확인한다.

첫 버전은 교회 정보와 담당자 권한 설정, 예배 안내 관리, 말씀·주보 작성과 게시, 카카오톡 공유를 다룬다. GitHub Pages 웹앱에서 사용 흐름을 검증한 뒤 iOS·Android 배포를 검토한다. 운영비 마련에는 자발적 후원 방식을 검토한다.

## 현재 개발 상태

| 영역 | 앱에서 확인할 수 있는 범위 | 남은 작업 |
| --- | --- | --- |
| 입장과 홈 | 6자리 교회 코드 입력, 영문 키패드 전환, 코드 없이 예시 교회 둘러보기. 관리자 개발 모드는 코드로 입장하며 교회 홈을 함께 사용한다. 하단에는 역할에 맞는 메뉴가 표시된다. | 실제 교회 코드 조회와 선택, QR 및 교회별 링크를 연결한다. 운영 계정과 교회별 관리자 권한은 Supabase에서 확인한다. |

성도 화면에서는 예시 교회의 **주보 → 오늘의 성경구절**을 연다. 개발용 관리자 모드에서는 **주보 가져오기·편집**과 **말씀 작성·편집**을 시험할 수 있다. [오늘의 교회](https://jordonpark.github.io/malsseum-alim/#entry)

## 사용 편의 기준

- **성도 홈**에는 **이번 주 주보**, **예배 안내**, **이번 주 말씀**을 큰 글씨와 큰 버튼으로 표시한다. 주일에는 **주보 → 오늘의 성경구절** 한 흐름으로 예배 본문을 읽는다. 온라인 예배 주소와 공유 링크가 등록되면 예배 안내나 받은 링크에서 바로 연다.
- **관리자 화면**에서는 **직접 작성**, **지난주 주보 복사**, **사진·PDF 가져오기** 중 원하는 방법으로 시작한다. 이후 검토, 게시, 카카오톡 공유 순서로 진행하며 각 화면에서 다음 할 일을 버튼에 적는다.
- **시범 운영**에서 어르신이 설명 없이 카톡 링크로 들어가 예배 시간과 설교 본문을 찾는지, 교회 담당자가 도움 없이 주보를 올리고 말씀 링크를 복사하는지 확인한다. 막힌 단계와 소요 시간을 기록한다.

## 화면 디자인

성도 화면은 따뜻한 아이보리 바탕에 연한 세이지색과 짙은 녹색을 사용한다. 둥근 카드와 넉넉한 여백으로 메뉴를 구분하고, 교회 홈과 빈 화면에는 펼친 책, 나뭇잎, 아침 햇살처럼 손그림 느낌의 작은 일러스트를 곁들인다. 교회 이름과 예배 시간, 이번 주 말씀을 그림보다 먼저 읽을 수 있도록 배치한다.

본문과 버튼에는 또렷한 글꼴과 충분한 대비를 적용한다. 일러스트는 여백에 배치하고, 메뉴는 글자와 익숙한 아이콘으로 구분한다. 글자 크기를 키워도 버튼과 내용이 잘리지 않도록 한다. 홈은 미세한 바람과 햇살, 주보·예배는 삽화의 가벼운 움직임, 말씀 화면은 책장이 넘어가는 대기 상태 모션을 사용한다. 글씨와 버튼은 고정하고, 기기에서 동작 줄이기를 켜면 반복 모션을 멈춘다. 관리자 화면도 같은 화면과 크기를 사용하며, 작성·검토·게시 버튼은 관련 메뉴에서 찾을 수 있게 한다.

### 한국 사용자에게 익숙한 화면 사용 방식

- 모바일 화면에는 아이콘과 한글 이름이 함께 있는 하단 메뉴를 둔다. 성도 화면의 주요 메뉴는 **홈 · 주보 · 예배 · 말씀**으로 구성하고, 현재 위치를 글자와 색으로 표시한다.
- 상세 화면 상단에는 **뒤로**와 화면 제목을 같은 위치에 둔다. 카카오톡에서 받은 링크는 해당 글을 바로 열며, 화면 위의 **교회 홈** 버튼으로 예배와 주보도 쉽게 찾을 수 있다.
- 목록에는 한 줄 제목과 날짜를 크게 표시하고, 행 전체를 눌러 상세를 열 수 있게 한다. **큰 글씨** 설정을 제공하고 휴대폰 글자 크기를 키워도 버튼이나 본문이 잘리지 않게 한다.
- 중요한 버튼에는 **주보 올리기**, **검토 요청**, **게시하기**, **카톡으로 보내기**처럼 눌렀을 때 일어나는 일을 적는다. 사진이나 PDF를 추가하는 메뉴는 큰 버튼과 함께 아래에서 열어 한 손으로 선택할 수 있게 한다.
- 시범 운영에서 어르신이 카카오톡 안에서 링크를 열어 예배 시간을 찾고 교회 홈으로 이동하는 과정을 설명 없이 수행할 수 있는지 확인한다.

## 성도 화면

- 성도는 회원가입과 로그인 없이 게시된 말씀을 읽고 듣는다. 홈은 오늘의 말씀과 듣기를 쉽게 찾을 수 있도록 큰 글씨와 큰 버튼을 사용한다.
- 처음 방문한 성도는 주보나 카톡으로 안내받은 교회 코드를 입력한다. 교회 이름과 지역을 확인하고 **우리 교회로 설정**을 누르면 같은 브라우저에서 다음 방문에도 해당 교회가 열린다. **교회 변경**에서 다른 코드를 입력할 수 있다.
- 교회 등록 시 DB가 **숫자 6자리**를 무작위로 발급한다. DB의 고유 제약으로 동시에 교회가 등록돼도 중복을 막는다. 발급 가능한 숫자 조합을 모두 쓰면 **영문 한 글자와 숫자 다섯 자리**로 발급한다. 주보에는 세 자리씩 나눠 표시할 수 있다. 입력란은 기본으로 숫자 키패드를 열고, 영문 입력으로 전환할 수 있다. 코드는 공백, 하이픈, 영문 대소문자 구분 없이 공개 교회 페이지를 찾는 데 사용한다.
- 카카오톡으로 받은 개별 말씀 링크는 교회 코드 입력 없이 해당 글을 바로 연다.
- 관리자가 지정한 주일 설교 본문은 해당 주일에 교회 홈에 표시한다.

- 교회 코드 형식이 맞지 않거나 등록된 교회를 찾을 수 없으면 **교회 코드를 다시 확인해 주세요**라고 안내한다. 입력한 숫자를 유지해 바로 수정할 수 있게 한다.

### 성도 설정

교회 홈 오른쪽 위의 톱니바퀴 아이콘을 누르면 설정이 열린다. 개발용 웹앱에서는 **큰 글씨**와 **교회 변경**을 제공한다. 실제 교회 조회를 연결하면 변경한 교회를 브라우저에 기억하고, 설정에 **이용 안내**와 **개인정보 처리방침**을 둔다.

## 관리자 계정과 교회 연결

- 관리자와 성도는 같은 교회 홈을 사용한다. 관리자 모드에서는 상단에 **관리자** 표시를 띄우고, 하단 **홈 · 주보 관리 · 말씀 관리 · 설정** 메뉴에서 편집과 설정을 바로 연다. 예배 안내는 교회 홈에서 열 수 있고, 예배시간 수정은 **주보 관리**에서 한다. **설정 → 교회 정보**에서 교회 이름을 편집할 수 있다. 개발용 앱은 변경한 이름을 같은 탭의 관리자 화면에 표시하며, 운영 시 교회 책임자가 수정한 이름을 DB에 저장한다. **관리자 모드 종료**는 설정에 둔다.
- 개발용 웹앱은 별도 계정 없이 코드로 예시 교회의 관리자 화면을 시험한다. 운영 단계에서는 카카오 또는 Google 계정으로 로그인하고, 교회 책임자가 계정을 승인할 때 교회별 역할을 지정한다.
- **교회 추가하기**에서 교회 이름과 지역으로 검색하거나 초대 링크로 소속 신청을 한다. 승인 전에는 **승인 대기 중**, 승인 후에는 **내 교회**에 표시한다. 목록에 없는 교회는 **새 교회 등록 요청**으로 연결한다.
- 관리자가 여러 교회에 연결된 경우 글을 작성하거나 게시할 교회를 선택한다. 게시와 수정 요청을 처리하는 쪽에서 관리자와 교회의 권한을 확인한다.

### 게시판 관리자 권한

성도는 로그인 없이 공개된 게시글을 읽는다. 게시판 글 작성은 승인된 교회 관리자에게만 허용하며, 권한은 교회별로 부여한다.

| 레벨 | 역할 | 권한 |
| --- | --- | --- |
| 1 | 작성 관리자 | 자기 교회 게시판 글과 말씀·주보 초안 작성, 본인 초안 수정, OCR 가져오기, 미리보기, 게시 요청 |
| 2 | 게시 관리자 | 작성 권한과 함께 소속 교회의 초안 검토, 게시, 공개 글 수정, 게시 취소, 카카오톡 공유 |
| 3 | 교회 책임자 | 게시 권한과 함께 교회 정보 관리, 관리자 초대·승인, 역할 변경과 권한 회수 |

작성 관리자가 **게시 요청**을 누르면 글은 검토 대기 상태가 된다. 게시 관리자나 교회 책임자가 게시하면 성도에게 공개된다. 수정이 필요하면 작성자에게 돌려보낸다. 한 사람이 교회를 운영하는 경우 교회 책임자가 작성부터 게시까지 진행할 수 있다.

게시글에는 마지막 게시·수정 담당자와 시각을 관리자 화면에 표시한다. 권한 변경은 교회 책임자가 처리하며, 마지막 책임자의 권한은 다른 책임자에게 이관한 뒤 회수할 수 있다. Supabase에서 요청 시 교회 소속과 역할을 검사한다.

### 개인정보 수집과 열람 범위

- **성도**는 로그인 없이 공개 콘텐츠를 이용한다. 성도의 이름, 연락처, 이메일을 입력받거나 교인 명부를 수집하지 않는다. 관리자 화면에도 성도 개인정보 조회 기능을 제공하지 않는다.
- **관리자 계정 신청자**에게만 로그인과 소속 승인에 필요한 이름 또는 표시 이름, 계정 식별 정보, 신청 교회를 받는다. 이메일과 연락처는 승인 또는 운영 연락에 필요한 경우에만 받는다.
- **관리자 정보**는 본인과 해당 교회 책임자만 필요한 범위에서 열람한다. 성도용 화면과 공개 조회 응답에는 관리자 계정 정보를 포함하지 않는다.
- 첫 버전에는 교인 명단 입력·파일 가져오기·저장 기능과 명단 데이터베이스를 두지 않는다. 공지에 인원 현황이 필요하면 개인을 식별할 수 없는 합계만 사용한다.
- 주보 OCR은 관리자 브라우저에서 처리한다. 원본 파일과 전체 추출 텍스트는 서버로 전송하지 않고, 개인정보를 제외한 항목만 임시저장과 게시 대상으로 사용한다.
- 주보나 게시글에서 이름·연락처가 나열된 명단이나 개인 기도 제목이 발견되면 해당 부분을 표시한다. 관리자가 제거한 뒤 게시할 수 있다. 전화번호·이메일 형식 검사를 적용하고, 이름이나 문맥처럼 자동으로 판단하기 어려운 내용은 게시 전 미리보기에서 확인한다.

### 교회 접속 QR

승인받은 관리자는 **내 교회**에서 교회 홈으로 연결되는 QR을 이미지로 내려받아 종이 주보나 안내문에 넣을 수 있다. 성도가 휴대폰 카메라로 스캔하면 코드 입력과 로그인 없이 교회 홈이 열린다. 인쇄물에는 6자리 교회 코드도 함께 안내할 수 있다.

### 교회 등록과 온라인 예배 링크

새 교회를 등록할 때 신청자가 교회 공식 홈페이지, 유튜브 채널, 온라인 예배 시청 주소를 선택 항목으로 입력할 수 있다. 해당 주소가 없으면 비워 두고 등록할 수 있다. 등록 후에는 해당 교회의 책임자가 주소를 추가·수정·삭제한다.

교회 홈에 등록된 주소만 **교회 홈페이지**, **유튜브 채널**, **온라인 예배 보기** 버튼으로 표시한다. 온라인 예배 주소를 누르면 해당 예배 영상이나 생중계 페이지가 열리며, 성도는 로그인 없이 시청 링크를 열 수 있다.

### 교단 표시와 교회 로고

교회 화면 상단에는 관리자 지정 로고, 소속 교단명 배지, 오늘의 교회 기본 아이콘 순으로 표시한다. 교단명 배지는 앱에서 만든 문자 표시이며, 공식 교표는 사용 권한을 확인한 뒤 등록한다. 개발용 웹앱에서는 GitHub 배포 설정으로 적용하고, 운영 단계에서는 승인받은 관리자가 교회 설정에서 변경한다.

### 기본 예배 일정

교회 책임자는 교회 설정에서 정기 예배의 이름, 요일, 시간, 장소를 한 번 등록한다. 새 주보에 기본 일정이 자동으로 채워지며, 담당자는 해당 주 주보에서 내용을 확인하고 필요하면 수정할 수 있다. 주보에서 시간을 수정해도 교회 설정의 기본 일정은 그대로 유지된다.

관리자는 **주보에서 예배시간 가져오기**에서 사진 여러 장이나 PDF를 읽어 예배 이름, 요일, 시간을 초안에 자동으로 채울 수 있다. 오전과 오후가 불분명하거나 일부 항목이 누락되면 **확인 필요**로 표시해 직접 보완할 수 있게 한다. 개발용 웹앱에서 확인한 시간은 **미리보기 적용**으로 같은 브라우저 탭의 관리자 화면에서 확인한다.

## 말씀 보내기

관리자는 공통 **말씀** 탭에서 **말씀 보내기**를 시작한다. 주보 작성과 별개로 새 말씀을 작성하거나 이미 게시한 말씀을 골라 보낼 수 있게 구현한다.

1. **작성.** 제목, 성경 구절, 전할 말씀을 입력한다. 입력 중 자동 저장하고 성도에게 보일 화면을 미리 볼 수 있다.
2. **게시.** 작성 관리자는 검토를 요청한다. 게시 관리자나 교회 책임자는 검토 후 게시할 수 있다. 게시 권한이 있는 관리자가 직접 작성한 말씀은 바로 게시할 수 있다.
3. **공유.** 게시된 말씀의 카카오톡 공유 문구를 검사한 뒤 미리 보여 준다. 관리자는 **카톡으로 보내기**로 교회 채팅방에 공유하거나, **예약용 메시지 복사**로 카카오톡에서 전송 시간을 정한다. 성도는 받은 링크로 해당 말씀을 로그인 없이 바로 연다.

시범 운영에서는 관리자가 주보 화면을 거치지 않고 말씀을 작성·게시·공유할 수 있는지, 성도가 받은 링크로 해당 말씀을 바로 열 수 있는지 확인한다.

## 말씀 작성과 임시저장

1. 관리자가 제목, 성경 구절, 묵상, 적용, 기도를 입력한다. 주일 말씀은 날짜와 설교 본문을 지정한다.
2. 입력이 잠시 멈추면 자동 임시저장한다. 화면을 벗어날 때도 마지막 변경분을 저장하도록 시도한다. 작성 화면에 **저장 중**, **임시저장 완료**와 마지막 저장 시각, 또는 **저장 실패**를 표시한다.
3. 같은 기기와 브라우저에서 임시저장 목록을 열면 제목과 마지막 수정 시각이 표시된다. 제목이 없으면 **제목 없는 말씀**으로 표시하고, 삭제 전에는 확인을 받는다.
4. 성도 화면을 미리 본 뒤 작성 관리자는 **게시 요청**, 게시 관리자와 교회 책임자는 **게시**를 누른다. 이미 게시한 글의 수정본은 게시에 성공한 시점에 성도 화면에 반영한다. 게시에 실패하면 임시저장본을 유지한다.

첫 버전의 초안은 브라우저에 저장한다. 화면에 **이 브라우저에 임시저장됩니다**라고 안내한다. 다른 기기에는 자동으로 동기화되지 않으며, 브라우저 데이터를 지우면 초안이 삭제될 수 있다.

## 주보 가져오기와 게시

소속 교회에서 권한을 승인받은 관리자(Admin)만 그 교회의 주보를 등록하고 OCR을 실행하거나, 역할에 따라 추출 내용을 수정·게시할 수 있다. 성도는 게시된 주보를 로그인 없이 읽는다.

관리자는 종이 주보를 촬영하거나 기존 이미지·PDF 파일을 올려 항목별 초안을 만들 수 있다. 텍스트가 들어 있는 PDF는 텍스트를 우선 추출하고, 사진이나 스캔본은 OCR로 읽는다.

1. **가져오기**에서 주보 파일과 발행일을 지정한다. 여러 페이지나 여러 단으로 구성된 주보는 페이지와 단 순서를 확인할 수 있도록 원본과 추출 내용을 함께 표시한다.
2. **항목 분류**에서 예배 일시·장소, 예배 순서, 설교 제목·성경 본문·설교자, 교회 소식과 행사 일정을 나눈다. 분류하기 어려운 내용은 기타 항목에 두고, 읽기 어려운 부분은 확인이 필요하다고 표시한다.
3. **검토**에서 담당자가 추출 내용을 원본과 비교해 수정한다. 특히 날짜, 시간, 성경 구절은 게시 전에 확인한다. 개인 연락처, 교인 명단, 개인 기도 제목 등은 공개 항목에 자동으로 넣지 않는다.
4. **게시**를 누르면 교회 홈의 **이번 주 주보**에서 성도가 로그인 없이 항목별로 읽을 수 있다. 주보의 예배일을 기준으로 해당 주 주보를 표시한다.

### 이번 주 말씀 자동 표시

주보 사진이나 PDF에서 추출한 설교 제목, 성경 구절, 설교자를 공통 주보 포맷의 **설교 말씀**에 자동으로 채운다. 관리자가 원본과 대조해 수정한 뒤 주보를 게시하면, 해당 예배일이 속한 주에 같은 내용을 교회 홈의 **이번 주 말씀**으로 표시한다. 성도는 홈에서 설교 제목, 구절, 설교자를 바로 확인할 수 있다. 날짜나 구절이 불분명하면 **확인 필요**로 표시하며, 확인되지 않은 설교 정보는 홈에 반영하지 않는다.

성경 본문의 기본 판본은 **성경전서 개역개정판**으로 한다. 성도는 **이번 주 주보 → 오늘의 성경구절**에서 해당 예배의 본문을 확인하고, 같은 구절을 큰 글씨로 열 수 있다. 개역개정 사용 허가와 데이터 연동 전의 예시 주보에는 요한복음 14장 27절을 **개역한글 · 예시 본문**으로 표시한다. 개역개정은 구절별 대한성서공회 공식 열람 링크로 연결한다. [대한성서공회 개역한글 사용 안내](https://bskorea.or.kr/bbs/board.php?bo_table=copyright_faq&wr_id=5) · [공식 링크 이용 안내](https://www.bskorea.or.kr/bbs/board.php?bo_table=copyright_faq&wr_id=9)

### 지난주 주보 복사

승인받은 관리자는 최근에 게시한 주보에서 **복사해서 작성**을 눌러 새 초안을 만든다. 예배 시간·장소와 예배 순서를 가져오고 새 발행일을 지정한다. 이전 설교 말씀과 날짜가 있는 공지·행사는 **확인 필요**로 표시하여 관리자가 수정하거나 제외하도록 한다. 복사한 글은 자동 임시저장하고, 관리자가 게시하면 성도 화면에 표시한다.

### 기본 주보 포맷

교회별 기존 주보 양식을 가져올 수 있다. OCR 결과와 직접 입력한 내용은 같은 기본 포맷으로 정리한다. 관리자는 이 포맷으로 검토하고, 성도는 같은 항목 순서로 읽는다.

| 항목 | 입력 내용 | 필수 여부 |
| --- | --- | --- |
| 주보 기본 정보 | 등록된 교회명, 발행일 또는 예배일 | 필수 |
| 예배 안내 | 예배 이름, 시간, 장소 또는 온라인 예배 링크. 예배별로 추가 가능 | 선택 |
| 예배 순서 | 순서명, 담당자, 찬송가 번호 등 | 선택 |
| 설교 말씀 | 설교 제목, 성경 구절, 설교자 | 선택 |
| 교회 소식 | 공지 제목과 내용 | 선택 |
| 행사 일정 | 행사명, 날짜, 시간, 장소 | 선택 |

OCR에서 읽지 못한 내용은 빈칸이나 **확인 필요**로 남긴다. 분류되지 않은 문장은 관리자 검토 목록에 두고 관리자가 항목을 지정하거나 제외한다. 게시하려면 날짜와 공개할 내용이 한 항목 이상 있어야 한다. 성도 화면에는 내용이 있는 항목만 표시한다.

### OCR 도구와 검증 기준

- **Tesseract.js**와 한국어 모델 `kor`로 사진과 스캔본을 관리자 브라우저 안에서 인식한다. 이 경로는 별도 OCR 서버 없이 GitHub Pages에서 실행할 수 있으며, 인식 작업에 주보 원본을 외부 OCR 서비스로 전송하지 않는다. [Tesseract.js](https://github.com/naptha/tesseract.js) · [한국어 모델](https://github.com/tesseract-ocr/tessdata/blob/main/kor.traineddata)
- **PDF.js**로 PDF를 연다. 텍스트가 들어 있는 페이지는 텍스트를 추출하고, 스캔 페이지는 이미지로 렌더링해 Tesseract.js로 읽는다. [PDF.js](https://mozilla.github.io/pdf.js/)
- 예배 순서, 설교 본문, 공지 등은 추출된 텍스트와 위치를 바탕으로 항목별 초안을 만든다. 관리자가 원본과 대조해 확정한 내용만 게시한다.

시범 교회의 텍스트 PDF, 스캔 PDF, 휴대폰 사진으로 테스트한다. 날짜·시간·성경 구절의 인식 오류, 여러 단의 읽기 순서, 가져오기부터 게시까지 걸리는 시간을 확인한다.

### 교회별 주보 인식 보정

- 처음에는 공통 규칙으로 주보를 읽는다. 관리자가 결과를 원본과 대조해 확정하면, 같은 교회의 같은 양식에서 반복 활용할 수 있는 항목명, 페이지·단 위치와 읽기 순서, 반복 오인식의 교정 규칙을 기록한다.
- 다음 주보에서 서식이 일치할 때 저장한 규칙을 적용해 새 이미지의 내용을 인식하고 초안을 채운다. 예를 들어 지난주에 왼쪽 두 번째 단의 **말씀선포**를 **설교 말씀**으로 바로잡았다면, 같은 위치와 제목을 다음 주보의 설교 칸을 찾는 단서로 사용한다. 이전 주의 날짜, 설교 제목, 구절이나 공지 본문을 새 주보에 넣는 데 이 규칙을 사용하지 않는다.
- 새 양식이거나 규칙이 현재 OCR 결과와 충돌하면 공통 규칙으로 돌아가고 **확인 필요**를 표시한다. 관리자는 잘못 적용된 규칙을 초기화할 수 있다. 보정 결과도 초안에만 적용하고 사람의 검토를 거쳐 게시한다.
- 원본 이미지와 전체 추출 텍스트는 브라우저에서 분석할 때만 사용한다. 서버에는 개인정보를 제외한 서식 정보와 보정 규칙만 교회별로 저장하며, 다른 교회와 공유하지 않는다.
- 시범 교회의 같은 서식으로 만든 여러 주의 주보에서 보정 전후의 수정 항목 수와 검토 시간을 비교한다. 특히 여러 페이지의 읽기 순서와 날짜·성경 구절의 오류를 확인한다.

## 카카오톡 공유와 예약

1. 게시가 완료된 글에서 **카카오톡 발송**을 누르면 제목과 안내 문구를 검사한 뒤 발송 화면을 바로 연다.
2. 발송 화면에는 교회 이름, 말씀 제목, 읽기 링크가 포함된 메시지와 **카카오톡으로 공유**, **예약용 메시지 복사** 버튼을 표시한다.
3. 바로 보낼 때는 카카오톡 공유 화면에서 교회 채팅방을 선택한다. 예약할 때는 복사한 메시지를 채팅방에 붙여넣고 카카오톡의 예약 메시지 기능으로 기기에 표시된 날짜와 시간을 정한다. [카카오톡 예약 메시지 안내](https://pf.kakao.com/_xbQtxaK/contents/posts/110427151)

GitHub Pages의 공개 말씀 화면으로 연결하고, 예약과 발송은 카카오톡에서 처리한다. 첫 버전의 전달 채널은 카카오톡이다.

### 공유 링크 유지

게시된 주보나 말씀을 수정해도 공유 링크 주소는 유지한다. 성도가 이미 받은 카카오톡 링크를 다시 열면 최신 게시본이 표시된다. 게시를 취소한 글은 같은 주소에서 **게시가 취소되었어요**라고 안내한다.

### 발송 문구 검사

- 브라우저에서 카톡에 실제로 들어갈 제목과 안내 문구를 검사한다.
- 명백한 욕설이나 비하 표현은 위치를 표시하고, 수정 후 재검사를 통과할 때까지 공유와 복사를 막는다.
- 문맥 확인이 필요한 표현에는 확인 안내를 띄우고, 관리자가 확인하면 계속 진행한다.
- 성경과 묵상에서 쓰이는 `죄`, `죽음`, `고난` 같은 표현은 단어만으로 차단하지 않는다.

## 첫 주보를 게시하고 성도에게 전달하기

1. **교회 설정.** 관리자는 카카오 또는 Google로 로그인하고 교회를 등록하거나 기존 교회의 승인을 받는다. 교회 이름과 지역을 확인하고, 온라인 예배 주소가 있으면 추가한다.
2. **주보 준비.** 관리자는 사진·PDF 가져오기, 지난주 주보 복사, 직접 작성 중 하나를 고른다. 파일을 가져오면 예배 안내, 예배 순서, 설교 말씀, 공지, 행사 일정이 공통 포맷의 초안에 들어간다.
3. **검토와 게시.** 관리자는 예배일, 시간, 설교 구절을 확인하고 성도 화면을 미리 본다. 게시가 끝나면 성도용 링크를 복사할 수 있다. 게시에 실패하면 초안을 유지하고 다시 시도할 수 있게 안내한다.
4. **카톡 전달.** 관리자는 제목과 링크를 교회 채팅방에 보낸다. 예약이 필요하면 카카오톡에서 전송 시간을 설정한다.
5. **성도 열람.** 성도는 카톡 링크로 해당 글을 바로 열거나 교회 QR·6자리 코드로 교회 홈에 들어간다. 홈에서 이번 주 주보, 예배 안내, 이번 주 말씀을 확인한다.

### 화면에 표시할 상태

| 상황 | 화면과 다음 행동 |
| --- | --- |
| 주보 분석 중 | 관리자에게 진행 상태를 표시한다. 완료되면 검토 화면으로 이동한다. |
| 인식에 실패한 항목이 있음 | 원본 옆에 확인이 필요한 부분을 표시한다. 관리자가 고치거나 직접 입력할 수 있다. |
| 이번 주에 게시한 주보가 없음 | 성도 홈에 **이번 주 주보가 아직 올라오지 않았어요**를 표시한다. 등록된 예배 안내와 온라인 예배 링크는 계속 이용할 수 있다. |
| 개역개정 본문 연동 전 | **이번 주 말씀**에 설교 제목과 확인된 구절 주소를 표시한다. **성경 읽기** 링크는 대한성서공회 공식 열람 페이지를 연다. [공식 링크 이용 안내](https://www.bskorea.or.kr/bbs/board.php?bo_table=copyright_faq&wr_id=9) |

### 시범 운영에서 확인할 일

- 관리자가 자신의 주보 사진 또는 PDF로 초안을 만들고, 잘못 인식된 시간을 고쳐 게시하고, 링크를 복사할 수 있다.
- 성도가 카카오톡 안에서 링크를 열어 로그인 없이 예배 시간과 설교 구절을 찾을 수 있다.
- 미게시 주보는 성도 화면에서 열리지 않고, 다른 교회 관리자는 해당 주보를 수정할 수 없다.
- 새 주보에 기본 예배 시간이 자동으로 채워지고, 해당 주의 시간을 수정해도 교회 설정의 기본 일정은 유지된다.
- 게시된 주보와 말씀을 수정해도 기존 카톡 링크에서 최신 게시본이 열리며, 게시를 취소하면 같은 주소에 안내가 표시된다.
- 잘못된 교회 코드를 입력하면 안내가 표시되고, 입력한 숫자를 그대로 고칠 수 있다.

## 운영 방식과 다음 구현

- **GitHub Pages**는 현재 예시 교회 콘텐츠와 개발용 관리자 화면을 호스팅한다. Supabase에 게시 기능을 연결한 뒤에는 새로 게시된 콘텐츠를 DB에서 읽는다.
- **Supabase Auth**로 관리자 카카오·Google 로그인을 연동한다. 로그인과 교회별 관리자 승인은 별도로 확인한다. [카카오 로그인](https://supabase.com/docs/guides/auth/social-sign-in/auth-kakao) · [Google 로그인](https://supabase.com/docs/guides/auth/social-sign-in/auth-google)
- **Supabase DB**에 교회 코드, 교회 정보, 관리자 소속·승인 상태, 말씀과 주보를 저장한다. 행 수준 보안(RLS)으로 관리자 소속 교회와 역할에 따라 초안 작성, 게시, 수정 및 권한 관리 요청을 제한한다. 로그인하지 않은 방문자는 공개 교회 정보와 게시된 콘텐츠만 읽을 수 있다. [Supabase 행 수준 보안](https://supabase.com/docs/guides/database/postgres/row-level-security)
- **관리자 브라우저**는 현재 주보 OCR, 말씀 작성, 초안 자동 저장과 관리자용 미리보기를 탭 안에서 처리한다. 운영 단계의 게시와 교회별 저장은 Supabase에 연결한다. 메시지 예약은 카카오톡에서 설정한다.
- 첫 연동에서는 승인된 관리자의 주보 게시와 성도의 코드·QR 접속을 확인한다. 작성 관리자의 직접 게시 요청, 다른 교회 관리자의 수정 요청, 로그인하지 않은 사용자의 미게시 콘텐츠 조회가 차단되는지도 검증한다.
- 개역개정 본문은 사용 허가 범위를 확인해 적용한다. 초기 사용 흐름은 예시 콘텐츠로 검증할 수 있다.
- 시범 교회에서 성도가 코드나 카톡 링크로 접속해 말씀을 읽고 들을 수 있는지, 담당자가 초안을 복구하고 게시한 뒤 카카오톡에서 예약할 수 있는지 확인한다.

## 보안 설계와 출시 검증

- **공개 범위.** 로그인하지 않은 방문자는 공개 교회 정보와 게시된 글만 읽는다. 교회 코드와 QR은 공개 페이지 주소로 사용한다. 초안, 검토 대기 글, 게시 취소된 내용, 관리자 계정 정보와 권한 변경 기록은 공개 조회 응답에서도 제외한다.
- **교회별 권한.** Supabase에서 모든 관리자 요청의 교회 소속, 승인 상태, 역할을 확인한다. 작성 관리자는 직접 게시할 수 없으며, 교회 책임자만 소속 승인과 권한 변경을 처리한다. 역할과 게시 상태 변경은 권한을 검증하는 전용 경로에서 처리한다. 권한 회수 후에는 기존 로그인 상태에서도 후속 요청을 거부한다.
- **데이터와 로그인.** 교인 명단은 수집하지 않는다. 주보 원본과 전체 OCR 결과는 관리자 브라우저에서 처리하고, 관리자 계정 정보는 본인과 해당 교회 책임자만 필요한 범위에서 열람한다. 웹앱에는 Supabase 공개용 키만 둔다. 서버용 비밀 키와 카카오·Google 로그인 비밀 값은 공개 코드나 로그에 넣지 않는다.
- **게시 내용.** 입력된 글은 일반 텍스트로 표시하고 외부 링크는 안전한 웹 주소 형식인지 확인한다. 검토 요청, 게시, 게시 취소, 관리자 권한 변경을 처리한 계정과 시각은 관리자용 기록에 남긴다.

- **SQL 인젝션 방지.** 교회 코드, 검색어, 게시글과 OCR 텍스트는 Supabase SDK의 입력값 또는 서버 함수의 매개변수로 전달한다. 입력값을 SQL 문장에 이어 붙이지 않는다. 정렬 기준은 미리 정한 값만 허용하고, 교회 코드는 서버에서도 숫자 6자리 또는 영문 한 글자와 숫자 다섯 자리인지 확인한다.

출시 전에 별도 테스트 교회와 계정으로 검증한다. 비로그인 상태에서 공개 글을 읽을 수 있는지, 미게시 글과 관리자 정보는 열리지 않는지, 작성 관리자가 직접 게시하거나 자신의 역할을 바꿀 수 없는지 확인한다. 다른 교회 글의 수정·삭제 요청과 권한 회수 후 요청도 거부되는지 확인한다. 특수문자가 포함된 입력은 데이터로만 처리되고 조회 범위와 게시 권한이 바뀌지 않는지 별도로 검증한다.
